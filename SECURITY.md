# Security policy

## Supported versions

| Line | PHP | Status |
|---|---|---|
| `3.x` (`main`) | 8.5+ | security and bug fixes |
| `1.x`, `2.x` | | not maintained |

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private vulnerability reporting
(<https://github.com/nandordudas/statemachine/security/advisories/new>) and include a minimal reproduction.

Race conditions and a way to persist a transition the definition does not allow count as security-relevant here.
Expect an answer within a few days.
